# URL Personal Shortener

A full-stack **personal URL shortener** with authentication, custom slugs, redirect handling, and per-user URL history.

- **Frontend:** React + Vite + Redux Toolkit + Tailwind CSS
- **Backend:** Spring Boot + Spring Security + JWT + MongoDB
- **Auth model:** Access/refresh token pair stored as HTTP-only cookies

---

## Features

- User registration and login (email or phone + password)
- JWT-based authentication with refresh flow
- Create short URLs with custom slugs
- User-specific URL uniqueness (same slug can exist for different users)
- Redirect endpoint for short links
- History page with each authenticated user’s links
- Protected routes on frontend + protected APIs on backend

## API Overview

Base API path: `http://localhost:8080/api`

### Auth
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/logout`
- `POST /auth/refresh`
- `GET /auth/get-user`

### URL
- `POST /urls` (auth required)
- `GET /urls/my` (auth required)

### Redirect
- `GET /r/{slug}-{shortId}`

Example redirect URL generated by backend:

```text
/r/my-blog-1a2b3cD
```

## Zero-Friction Local Setup (copy/paste)

This section is written so you can run the project with minimal manual data entry.

## 1) Prerequisites

Install these once:
- Java 21
- Maven (or use the included `./mvnw` wrapper)
- Node.js 20+
- MongoDB 6+ (local) **or** Docker

## 2) Start MongoDB (Docker quick option)

```bash
docker run -d --name url-shortner-mongo -p 27017:27017 mongo:7
```

If container already exists, start it:

```bash
docker start url-shortner-mongo
```

## 3) Backend environment file

Create `backend/.env`:

```env
MONGODB_HOST=localhost
MONGODB_PORT=27017
MONGODB_DATABASE=url_shortener
JWT_ACCESS_SECRET=dev_access_secret_change_me_please_1234567890
JWT_REFRESH_SECRET=dev_refresh_secret_change_me_please_1234567890
JWT_ACCESS_EXPIRATION=900000
JWT_REFRESH_EXPIRATION=604800000
```

> The backend uses placeholders from `application.properties`; with `spring-dotenv`, the `.env` file is loaded automatically.

## 4) Run backend

```bash
cd backend
./mvnw spring-boot:run
```

Backend will run at: `http://localhost:8080`

## 5) Run frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend will run at: `http://localhost:5173`

## Typical User Flow

1. Open `http://localhost:5173/auth`
2. Register a new account
3. Login
4. Create short URLs from Home page (Long URL + custom slug)
5. Access short URL path (e.g. `/r/my-slug-xxxxxxx`)
6. See all created URLs in history section

## Request/Response Examples

## Register

`POST /api/auth/register`

```json
{
  "name": "Test User",
  "email": "test@example.com",
  "phoneNo": "+919876543210",
  "password": "secret123"
}
```

Response contains tokens and user payload; cookies are also set by backend.

## Login

`POST /api/auth/login`

```json
{
  "username": "test@example.com",
  "password": "secret123"
}
```

## Create URL

`POST /api/urls`

```json
{
  "slug": "my-article",
  "originalUrl": "https://example.com/blog/my-long-article"
}
```

Success response includes `shortUrl` (path format `/r/{slug}-{shortId}`).

---

## Validation Rules

- `slug` is required and max 100 chars
- `originalUrl` must start with `http://`, `https://`, or `ftp://`
- Password must be at least 6 chars
- Slug must be unique **per user**

---

## Security Notes

- Cookies are `HttpOnly` and `SameSite=Lax`
- `secure=false` in current local configuration (for HTTP local dev)
- CORS is configured for `http://localhost:5173`

For production:
- switch cookies to `secure=true`
- configure CORS to your deployed frontend origin
- use strong, long JWT secrets
- use HTTPS only

## Troubleshooting

### 401 Unauthorized on protected endpoints
- Make sure login is successful
- Ensure frontend requests use `withCredentials: true`
- Confirm backend is running on port `8080`

### CORS errors
- Frontend must run at `http://localhost:5173`
- Backend `CorsConfig` currently allows that origin only

### Mongo connection errors
- Verify MongoDB is running on host/port from backend `.env`
- Check database name and all `.env` keys

### Redirect goes to `/not-found`
- The short ID does not exist (or link was mistyped)
- The redirect controller falls back to frontend `/not-found`
